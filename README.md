# Hora do Dia – Exercício em JavaScript

Exercício desenvolvido com o objetivo de criar uma funcionalidade de **Hora do Dia**, utilizando **JavaScript** para interação dinâmica com o usuário.

O projeto aplica conceitos de **lógica de programação**, **manipulação de datas e horários** e **interação com a interface**, permitindo exibir informações de acordo com o período do dia.

Este repositório representa um exercício prático de aprendizado e consolidação dos conhecimentos em JavaScript.
